# EduVulcan2.0

Nowoczesny elektroniczny dziennik ocen.

## Opis projektu

EduVulcan2.0 to aplikacja internetowa do zarządzania uczniami i ich ocenami.

## Technologie

- Python i Flask
- MySQL
- HTML, CSS, JavaScript
- Docker i Docker Compose
- GitHub Actions

## Funkcjonalności

- Dodawanie uczniów
- Dodawanie ocen
- Wyświetlanie ocen w tabelach
- Walidacja formularzy
- Dashboard ze statystykami
- Trwałe przechowywanie danych
- Automatyczne testy CI/CD

## Status projektu

Projekt w trakcie realizacji.
